# Olá, eu sou o Gustavo Carvalho! 👋

### 🚀 Desenvolvedor Web Full-Stack

Desenvolvedor Web focado na construção de aplicações completas, performáticas e escaláveis utilizando o ecossistema JavaScript moderno. 

Minha trajetória na tecnologia começou no design e desenvolvimento de interfaces de alta conversão (Landing Pages) atuando como freelancer — onde consolidei forte domínio em estruturação visual, responsividade, prototipação no Figma e entregas reais para clientes. Hoje, uno essa visão de produto e experiência do usuário à engenharia de software Full-Stack, construindo aplicações de ponta a ponta: do layout à arquitetura de banco de dados e containerização.
